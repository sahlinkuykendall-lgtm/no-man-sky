# Project Ranger (working title)

A Godot 4 space game: turn-based, isometric space trading, combat and missions inspired by *Space Rangers 2*, plus first-person open-world planet exploration, survival and crafting inspired by *No Man's Sky*. Planned for 8–16 player multiplayer with a story about an invading machine race, the Ascendancy.

**Read the master design doc first:** [`docs/MASTER_DESIGN.md`](docs/MASTER_DESIGN.md)

Status: pre-production (design phase).
